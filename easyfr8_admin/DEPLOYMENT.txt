════════════════════════════════════════════════════════════════
  PART 1 — FRONTEND (React/Vite Static Site)
════════════════════════════════════════════════════════════════

FILE:   easyfr8_frontend.zip
UPLOAD: /www/wwwroot/easyfr8.vnvision.in

STEPS:
  1. In aaPanel → Website → Add Site
       Domain:   easyfr8.vnvision.in
       Root Dir: /www/wwwroot/easyfr8.vnvision.in
       PHP:      Pure Static

  2. In aaPanel → File Manager → navigate to /www/wwwroot/easyfr8.vnvision.in/
  3. Delete any default placeholder files
  4. Upload easyfr8_frontend.zip
  5. Right-click ZIP → Extract (extract here)
  6. Verify index.html is at: /www/wwwroot/easyfr8.vnvision.in/index.html

NGINX SITE CONFIG (aaPanel → Website → Settings → Config):
  Add inside the server { } block:

      # React Router SPA fallback
      location / {
          try_files $uri $uri/ /index.html;
      }

      # Proxy API to Next.js backend
      location /api/ {
          proxy_pass http://127.0.0.1:3001;
          proxy_http_version 1.1;
          proxy_set_header Upgrade $http_upgrade;
          proxy_set_header Connection 'upgrade';
          proxy_set_header Host $host;
          proxy_set_header X-Real-IP $remote_addr;
          proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
          proxy_set_header X-Forwarded-Proto $scheme;
          proxy_cache_bypass $http_upgrade;
      }

      # Proxy images from Next.js
      location /images/ {
          proxy_pass http://127.0.0.1:3001;
          proxy_http_version 1.1;
          proxy_set_header Host $host;
          proxy_set_header X-Real-IP $remote_addr;
          proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
          proxy_set_header X-Forwarded-Proto $scheme;
      }

      # Proxy uploads from Next.js
      location /uploads/ {
          proxy_pass http://127.0.0.1:3001;
          proxy_http_version 1.1;
          proxy_set_header Host $host;
          proxy_set_header X-Real-IP $remote_addr;
          proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
          proxy_set_header X-Forwarded-Proto $scheme;
      }


════════════════════════════════════════════════════════════════
  PART 2 — BACKEND API + ADMIN PANEL (Next.js on port 3001)
════════════════════════════════════════════════════════════════

FILE:   easyfr8_api.zip
UPLOAD: /www/wwwroot/easyfr8_api

STEPS:
  1. Create directory (SSH terminal):
       mkdir -p /www/wwwroot/easyfr8_api

  2. In aaPanel → File Manager → navigate to /www/wwwroot/easyfr8_api/
  3. Upload easyfr8_api.zip
  4. Right-click ZIP → Extract (extract here)

  5. Configure environment (SSH terminal):
       cd /www/wwwroot/easyfr8_api
       cp .env.production.example .env.production
       nano .env.production

     Fill in MySQL credentials from aaPanel:
       DB_HOST=127.0.0.1
       DB_PORT=3306
       DB_DATABASE=easyfr8            ← your aaPanel DB name
       DB_USERNAME=easyfr8_user       ← your aaPanel DB username
       DB_PASSWORD=your_password      ← your aaPanel DB password

     Set a strong JWT secret:
       JWT_SECRET=change_to_long_random_string_here

  6. Install dependencies:
       npm install --production

  7. Run database migration (FIRST TIME ONLY):
       node lib/migrate.js

  8. Start with PM2:
       pm2 start npm --name "easyfr8-api" -- start
       pm2 save
       pm2 startup
       (Run the command that pm2 startup prints)

  9. Verify server is running:
       pm2 status
       pm2 logs easyfr8-api --lines 20


════════════════════════════════════════════════════════════════
  PART 3 — DATABASE SETUP
════════════════════════════════════════════════════════════════

  1. aaPanel → Database → Add Database
       Name:     easyfr8
       Username: easyfr8_user
       Password: (strong password)

  2. Import schema via SSH:
       mysql -u easyfr8_user -p easyfr8 < /www/wwwroot/easyfr8_api/lib/schema.sql

     OR let the migration script create tables automatically:
       node /www/wwwroot/easyfr8_api/lib/migrate.js
